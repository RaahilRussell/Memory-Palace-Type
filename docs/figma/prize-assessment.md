We organized all 29 source memories into native browsing and recovery states, built five shared component families, and verified that one component edit reached all 34 checked instances. Nine Figma variables now feed the running lobby. Our presentation embeds the actual prototype, so judges can inspect the same decisions that reach the product.”

Do not claim Figma generated the 3D room, that these measurements prove time saved, or that the local prototype is integrated with the wider backend. The visible Figma link is a route to evidence; it is not itself the prize argument.
